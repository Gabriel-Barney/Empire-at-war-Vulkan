# Which CTest entries are not purely synthetic (cmake/AlamoTestSuites.cmake; README.md "Test suites").
#
#   <test name, or ^regex$>  <entry> [<entry>...]
#
# An entry is <suite>[+<suite>][:<need>,<need>...]. Suites: synthetic, retail, vulkan, traces. Needs (checked by
# alamo_test_gate before the test runs): foc (ALAMO_FOC_DATA), eaw (ALAMO_EAW_DATA), traces (ALAMO_Q2_TRACES), vulkan
# (a Vulkan 1.3 device), file:<path>. retail defaults to foc, vulkan to vulkan, traces to traces.
#
# A trailing "optional" marks a rule whose test exists only in some configurations (no stale-rule warning).
#
# The first entry keeps the test's name; each further entry adds a companion <name>_<suite>[_<suite>] that runs the
# same command behind the gate. "synthetic", when present, must come first: the test then runs as is with game data
# and Vulkan drivers hidden. A test that is not listed here is synthetic only.
#
# Classified 2026-11-21 by running every entry with and without game data and with and without Vulkan drivers
# (VK_LOADER_DRIVERS_DISABLE=*): a test whose output changed, or that printed a skip line, uses that prerequisite.
# When you add a data or GPU part to a test, add its line here; check with dev.cmd suite synthetic and dev.cmd suite all.
