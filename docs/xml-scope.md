# XML field coverage

## Out-of-scope tag-ledger rows

- **multiplayer** covers network-only lobby, synchronization, and campaign features. Fields used during single-player skirmishes remain in scope.
- **hardware detection** covers the original hardware classifier. The Vulkan port supplies its own settings.
- **graphic detail levels** covers the original renderer's detail presets.
- **debug keys** covers retail developer key bindings.
- **localised splash / credits** covers the original localized splash screens and menu overlays (the credits roll's
  logos are in scope since #458).
